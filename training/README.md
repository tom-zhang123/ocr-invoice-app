# 离线训练约定

## 目标

先微调 PP-OCRv6-small Recognition（文字识别）模型，不重新训练现有表格定位逻辑。优先积累以下字段：

- `qty`：数量和斜线干扰
- `exp` / `mfg`：手写日期
- `sku`：印刷条码及尾部勾线
- `batch`：字母数字混合批次号

## 数据闭环

```text
原始图片
  -> 当前模型识别
  -> 操作员核实并修改
  -> 保存原图、单元格裁图、原值和最终值
  -> 数据质量检查
  -> 按整张单据划分训练集和验证集
  -> 离线微调
  -> 固定验证集对比
  -> 人工发布带版本号的模型
```

不能把同一张单据裁出的单元格同时放进训练集和验证集，否则准确率会虚高。

## 本地目录

```text
training/
|-- datasets/
|   `-- 2026-09-v1/
|       |-- source/
|       |-- cells/
|       |-- train.jsonl
|       `-- validation.jsonl
|-- runs/
|   `-- 2026-09-v1/
models/
`-- custom/
    `-- 2026-09-v1/
```

`training/datasets`、`training/runs` 和 `models/custom` 均被 Git（版本管理）忽略。

每条标注建议使用 JSONL（逐行 JSON）：

```json
{"document_id":"doc-0001","field":"qty","image":"cells/qty/000001.png","ocr_text":"625","label":"25","verified":true}
```

## 首轮数据要求

- 建议收集 200 至 500 张经过人工核实的单据
- 保留不同手机、角度、光线、纸张弯曲和笔迹
- 删除无法确认真值、严重截断或非目标单据
- 训练集与验证集按 `document_id` 拆分
- SKU（商品编码）、数量、日期和批次分别统计字符分布

## 发布门槛

新模型至少需要满足：

- 固定验证集行数不下降
- SKU（商品编码）精确命中率不下降
- 数量精确命中率高于当前基线
- 日期合法率提高，不能增加错误自动纠正
- CPU（处理器）耗时和峰值内存处于部署预算内
- 可以回退到上一模型版本

训练脚本和模型转换将在收集到第一批已核实数据后实现，不能用未标注图片直接训练。
